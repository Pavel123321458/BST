# Техническое задание на лабораторную работу 1

## Назначение

Реализовать шаблонное сбалансированное бинарное дерево поиска и множество на его основе. Обеспечить консольную проверку операций, автоматические тесты и измерение зависимости времени работы от числа элементов.

## Структура программы

`AvlTree<T, Compare>` хранит узлы с полями `value`, `left`, `right`, `height`. Связи и владение выражены через `std::unique_ptr<Node>`. Узлы выделяются динамически. Балансировка реализована четырьмя вариантами поворотов. Готовые стандартные контейнеры-деревья в реализации не используются.

`TreeSet<T>` использует `AvlTree<T>`. Сравнение ключей должно задавать строгий слабый порядок; ключи, эквивалентные по сравнению, считаются одинаковыми. Консоль работает с `int`; отдельный пункт демонстрирует `double` и `std::string`. Тесты проверяют все три типа. Для операций ввода/вывода пользовательскому типу нужны потоковые операторы.

## Поведение операций

- Вставка и удаление возвращают признак изменения. Повторная вставка и удаление отсутствующего ключа возвращают `false`.
- Поиск возвращает признак наличия; получение отсутствующего поддерева выбрасывает `std::out_of_range`.
- `map` заново вставляет преобразованные значения в дерево, чтобы сохранить порядок поиска. Совпадающие результаты объединяются. Тип результата совпадает с типом исходного дерева.
- `where` строит новое дерево из значений, удовлетворяющих предикату. `reduce` обходит значения по возрастанию, начиная с заданного аккумулятора; на пустой коллекции возвращает аккумулятор.
- Извлечение поддерева делает независимую глубокую копию. Вхождение означает совпадение значений **и формы** целого поддерева. Пустое поддерево входит в любое дерево.
- Поддерживаются обходы КЛП, КПЛ, ЛКП, ЛПК, ПКЛ, ПЛК.
- Сохранение и загрузка используют КЛП с маркерами пустых ссылок. Пример: `( 2 ( 1 # # ) ( 3 # # ) )`. Парсер проверяет синтаксис, порядок ключей и AVL-баланс; повреждённый ввод вызывает `std::invalid_argument`.
- Операции множества возвращают новые множества. Равенство зависит от элементов, а не от формы дерева.

Консоль предоставляет ручное заполнение, генерацию с заданным числом попыток, диапазоном и seed, просмотр результатов и сообщения об ошибках. В выводе больших коллекций показываются первые 100 элементов.

## Проверка и измерения

Тесты: пустое дерево, дубликаты, четыре случая поворотов, все виды удаления, шесть обходов, копирование и перемещение, случайные операции в сравнении со `std::set`, функциональные операции, поддеревья, сериализация трёх типов, неверный ввод и операции множества.

Измеряются вставка, поиск и удаление на 10^4, 10^5 и 10^6 элементах, по три повтора для каждого из трёх порядков вставки. Построение исходных массивов и проверка инвариантов исключены из измеряемого интервала. Результаты сохраняются в CSV, графики строятся по медианам повторов.

## Оценка сложности

Для n узлов AVL-дерева поиск, вставка и удаление занимают O(log n), обход и копирование — O(n), дополнительная глубина рекурсии — O(log n). `map` и `where` в этой реализации занимают O(n log n), поскольку создают новое сбалансированное дерево последовательными вставками. `reduce` — O(n). Память под дерево — O(n).
