# Протокол проверки

Проверка выполнена 27 октября 2026 года на Windows x64, GCC 14.2.0 из Code::Blocks. Компиляция: C++17, `-O2 -Wall -Wextra -Wpedantic -static`. Все пять исполняемых файлов собраны без предупреждений.

## Корректность

- ЛР 1: 12 групп тестов, ошибок 0. Включают 15 000 случайных операций с эталоном `std::set` и построение/удаление дерева из 20 000 последовательно добавленных ключей.
- ЛР 2: 9 групп тестов, ошибок 0. По 5 000 случайных операций для каждого словаря с эталоном `std::map`; арифметика проверена для всех сочетаний двух способов хранения.
- Через стандартный ввод проверены сценарии обоих меню, в том числе восстановление после ошибочного ввода, очень длинное некорректное число, переключение хранилища, завершение по EOF.
- Сохранение и последующая загрузка вектора через меню проверены с реальным файлом; записанное содержимое сверено с ожидаемым.
- Графики PNG открыты и визуально проверены: подписи, легенды и кривые читаются. SVG сохранены рядом.

Полные результаты: `lab1_tests.txt`, `lab2_tests.txt`, `console_checks.txt`.

## Производительность

В `lab1.csv` записано 27 замеров: 3 размера × 3 порядка × 3 повтора. Максимальный размер — 1 000 000 узлов. В `lab2.csv` — 54 замера: 3 размера × 3 порядка × 3 повтора × 2 реализации. В каждой строке второй серии измерены 100 000 запросов.

Все серии завершились успешно. Контрольные суммы проверены внутри программы измерений. Генерация исходных данных и проверка результата не включены в измеряемые интервалы. Графики показывают медианы трёх повторов.

Измерения на 10^7 и 10^8 узлах не проводились. Конфигурации отладчика VS Code и альтернативная CMake-сборка подготовлены; фактическая проверка сборки выполнена через PowerShell-скрипт. Интерфейс самого VS Code автоматически не управлялся.
