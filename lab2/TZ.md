# Техническое задание на лабораторную работу 2

## Назначение

Реализовать разреженный вектор вещественных чисел и сравнить два метода организации и поиска ненулевых элементов: AVL-дерево и отсортированную последовательность с двоичным поиском. Предоставить консольный интерфейс, тесты, сохранение данных и выгрузку измерений.

## Данные и интерфейсы

`SparseVector` хранит размерность N и словарь пар `(индекс, значение)`. Отсутствие индекса означает нулевой элемент. Нулевые значения не занимают узлы или ячейки словаря. Значения имеют тип `double`; индексы — `std::size_t`. В консоли размерность ограничена 10^9, генерация — 10^6 ненулевых элементов.

`IDictionary<K,V>` задаёт `GetCount`, `GetCapacity`, `Get`, `ContainsKey`, `Add`, `Set`, `Remove`, `ForEach`. `Add` запрещает повторные ключи, `Set` добавляет или заменяет. `Get` и `Remove` выбрасывают `std::out_of_range` для отсутствующего ключа.

Две реализации:

- `AvlDictionary<K,V>` использует шаблонное дерево из ЛР 1. Ключами дерева являются записи `Entry<K,V>`, сравниваемые только по ключу. Вместимость дерева равна числу выделенных узлов.
- `SortedDictionary<K,V>` хранит отсортированную последовательность записей в `std::vector`. Массив используется для владения памятью и сдвига записей; двоичный поиск реализован самостоятельно. Вместимость равна `vector::capacity()`.

`std::map` и другие готовые реализации поиска не используются в прикладном коде. `std::map` служит эталоном только в тестах.

## Операции разреженного вектора

1. Создание по размерности, ручной ввод пар и генерация.
2. Получение значения по индексу; для отсутствующего допустимого индекса возвращается ноль.
3. Присваивание, включая удаление сохранённой записи при присваивании нуля.
4. Сложение двух векторов одной размерности, умножение на число и скалярное произведение.
5. Переключение структуры хранения с сохранением значений.
6. Просмотр ненулевых элементов; при N ≤ 50 — также полный вид.
7. Сохранение и загрузка структурированного текстового файла.
8. Сравнение времени поиска и отдельная программа серийных замеров.

Индексы вне диапазона отклоняются. Для арифметики проверяется совпадение размерностей; NaN, бесконечности и переполнение результата отклоняются. Сложение и умножение создают новые векторы. Сравнение с нулём точное, произвольный epsilon не применяется.

## Формат файла

```text
SPARSE_VECTOR 1
12 3
0 2.5
4 -3
11 7
```

Первая строка задаёт формат и версию. Вторая содержит размерность и число ненулевых элементов. Далее идут пары индексов и значений. Числа сохраняются с точностью, достаточной для восстановления `double`. Формат не зависит от выбранного способа поиска: файл, записанный одной реализацией, загружается другой.

Загрузка проверяет заголовок, количество записей, допустимость индексов, ненулевые конечные значения, отсутствие повторов и лишнего текста. При ошибке исходный вектор в меню сохраняется, так как загрузка сначала создаёт временный объект.

## Методика сравнения

Для каждого размера создаётся одна последовательность уникальных индексов и значений. Оба алгоритма получают одинаковый порядок вставки и одинаковые 100 000 запросов. Размерности равны 10k, где k — число ненулевых элементов; примерно 10% случайных запросов попадают в ненулевые элементы.

Проверяются возрастающий, убывающий и случайный порядки. Построение структуры и поиск измеряются отдельно с помощью `std::chrono::steady_clock`. Генерация данных и вычисление эталонного ответа выполняются вне измерения. В каждом случае выполняются три повтора с фиксированными seed, порядок запуска двух алгоритмов чередуется. Контрольная сумма найденных значений сверяется с независимым расчётом.

Размеры проведённой серии: k = 1000, 5000, 20000. На графиках — медианы, в CSV — все повторы. Для массивной реализации построение в обратном порядке существенно дороже, чем поиск в уже готовой структуре; эти величины не объединяются.

## Проверки и сложность

Словари тестируются на случайных операциях с эталоном `std::map`. Арифметика разреженных векторов сравнивается с плотными массивами для всех четырёх сочетаний двух структур. Проверяются границы, нули, дубликаты, разные размерности, переполнение, копирование, преобразование хранилища и повреждённые файлы.

При k ненулевых элементах оба способа ищут ключ за O(log k). AVL вставляет и удаляет за O(log k); отсортированный массив — за O(k) в худшем случае из-за сдвигов. Построение AVL — O(k log k), массива — O(k²) в худшем случае. Хранимая память пропорциональна k, а не N. Для обоих способов сумма векторов и скалярное произведение реализованы через операции словаря, без выделения массива размерности N.
